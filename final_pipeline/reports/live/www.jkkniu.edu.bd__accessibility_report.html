empty_link_text  •  UF-00054
High Custom Links WCAG 2.4.4 Link Purpose (In Context) Level A Custom automated finding
View issue details and remediation

Why this matters

A link without meaningful text or another accessible name may be unusable for screen-reader users.

Location

DOM selector: a#scroll-top | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<a class="scroll-top d-flex align-items-center justify-content-center" href="#" id="scroll-top"><i class="bi bi-arrow-up-short"></i></a>

Custom scanner evidence

Link has no accessible name. Add meaningful link text, aria-label, or image alt text.

Recommended change

Provide descriptive visible link text or an appropriate accessible name for icon-only links.

Suggested code pattern 

<a aria-label="Describe link destination" class="scroll-top d-flex align-items-center justify-content-center" href="#" id="scroll-top"><i class="bi bi-arrow-up-short"></i></a>

Replace placeholder text with wording that correctly reflects the real page context.

Manual review

Required: Yes

The computed accessible name should be checked in the rendered page.
