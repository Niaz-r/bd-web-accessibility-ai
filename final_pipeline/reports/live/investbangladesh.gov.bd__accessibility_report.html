High axe Color contrast WCAG 1.4.3 Contrast (Minimum) Level AA Axe automated finding
View issue details and remediation

Why this matters

Affected HTML 

<p class="bid-section-sub-2ndtitle">Excluding routine investment registrations</p>

axe automated evidence 

Fix any of the following:
  Element has insufficient color contrast of 3.91 (foreground color: #797979, background color: #f4f3ed, font size: 12.0pt (16px), font weight: normal). Expected contrast ratio of 4.5:1

axe description

Ensure the contrast between foreground and background colors meets WCAG 2 AA minimum contrast ratio thresholds

Recommended change
