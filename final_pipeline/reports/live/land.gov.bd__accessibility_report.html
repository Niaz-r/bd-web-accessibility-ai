#001

Image alternative text may not be descriptive

non_descriptive_alt  •  UF-00001
Medium Custom Images WCAG 1.1.1 Non-text Content Level A Custom automated finding Context-aware recommendation
View issue details and remediation

Why this matters

Although the image has an alt attribute, generic text such as 'image', 'thumbnail', 'news image', 'event image', or a filename may not communicate the image's actual content or purpose.

Location

DOM selector: html > body.noto_sans_bengali_c54029d0-module__Qux_Ra__className > div:nth-of-type(3) > div:nth-of-type(3) > img.w-full.2xl:container | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<img alt="image" class="w-full 2xl:container 2xl:mx-auto object-cover" data-nimg="1" decoding="async" height="1000" loading="lazy" src="/_next/image?url=%2Fimages%2Fdhaka_line_6.png&amp;w=2048&amp;q=75" srcset="/_next/image?url=%2Fimages%2Fdhaka_line_6.png&amp;w=1080&amp;q=75 1x, /_next/image?url=%2Fimages%2Fdhaka_line_6.png&amp;w=2048&amp;q=75 2x" style="color:transparent" width="1000"/>

Custom scanner evidence

Alt text is generic and does not describe the image's content or purpose.

Recommended change

Review the purpose of the image and replace generic or filename-like alternative text with a concise description that communicates the same relevant information or function. If the image is purely decorative, use alt="" instead.

Context-Aware Recommendation

Replace the generic alt text “image” after visually inspecting the image. The surrounding context “নিবন্ধন করার জন্য কি কোন নির্দিষ্ট সময়সীমা রয়েছে?” can guide the description, but should not be copied as alt text unless it accurately represents the image.

Why this suggestion was made: The current alt attribute exists but appears non-descriptive. Context provides evidence about the related content, not proof of the image's visual content.

Evidence: nearby heading Context confidence: medium Language: bn Decision: GENERIC_ALT_CONTEXT_AVAILABLE

Recommended action: replace generic alt after visual review

Visual review required

The surrounding text provides contextual evidence, but the image itself must be inspected before final alternative text is written.

Human verification: Required before implementation.

This recommendation was generated by the proposed deterministic contextual decision engine. Context confidence describes the strength of the extracted contextual evidence, not WCAG conformance certainty.

Suggested code pattern 

<img alt="[Replace with a meaningful context-specific description]" class="w-full 2xl:container 2xl:mx-auto object-cover" data-nimg="1" decoding="async" height="1000" loading="lazy" src="/_next/image?url=%2Fimages%2Fdhaka_line_6.png&amp;w=2048&amp;q=75" srcset="/_next/image?url=%2Fimages%2Fdhaka_line_6.png&amp;w=1080&amp;q=75 1x, /_next/image?url=%2Fimages%2Fdhaka_line_6.png&amp;w=2048&amp;q=75 2x" style="color:transparent" width="1000"/>

#025

Text color contrast requires review

color-contrast  •  UF-00025
Review axe — manual review Color contrast WCAG 1.4.3 Contrast (Minimum) Level AA Manual review required
View issue details and remediation

Why this matters

Insufficient contrast between text and its background can make content difficult to read for users with low vision or color-vision deficiencies.

Location

DOM selector: .text-32 | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<h3 class="text-32 leading-[31px] lg:text-48 lg:leading-[36px] font-bold text-secondary pt-8">১৬১২২</h3>

axe automated evidence 

Fix any of the following:
  Element's background color could not be determined because it is overlapped by another element

axe description

Ensure the contrast between foreground and background colors meets WCAG 2 AA minimum contrast ratio thresholds

Recommended change

Check the computed foreground and background colors of the affected text. Normal-sized text should generally have a contrast ratio of at least 4.5:1, while qualifying large text should generally have a ratio of at least 3:1.

Manual review

Required: Yes

axe returned this finding as incomplete when contrast could not be conclusively evaluated automatically. Background images, gradients, transparency, overlapping elements, or other rendered styling can require manual inspection.
