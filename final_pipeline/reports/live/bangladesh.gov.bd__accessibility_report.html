#001

Text color contrast requires review

color-contrast  •  UF-00001
High axe Color contrast WCAG 1.4.3 Contrast (Minimum) Level AA Axe automated finding
View issue details and remediation

Why this matters

Insufficient contrast between text and its background can make content difficult to read for users with low vision or color-vision deficiencies.

Location

DOM selector: .bangladesh-header-widget-current-date | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<p class="bangladesh-header-widget-current-date"> ২৭ আগস্ট ২০২৬ </p>

axe automated evidence 

Fix any of the following:
  Element has insufficient color contrast of 3.21 (foreground color: #ffffff, background color: #00a63e, font size: 9.0pt (12px), font weight: normal). Expected contrast ratio of 4.5:1

axe description

Ensure the contrast between foreground and background colors meets WCAG 2 AA minimum contrast ratio thresholds

Recommended change

Check the computed foreground and background colors of the affected text. Normal-sized text should generally have a contrast ratio of at least 4.5:1, while qualifying large text should generally have a ratio of at least 3:1.

Manual review

Required: Yes

axe returned this finding as incomplete when contrast could not be conclusively evaluated automatically. Background images, gradients, transparency, overlapping elements, or other rendered styling can require manual inspection.

Location

Affected HTML

axe automated evidence 

Fix all of the following:
  Element is in tab order and does not have accessible text

Fix any of the following:
  Element does not have text that is visible to screen readers
  aria-label attribute does not exist or is empty
  aria-labelledby attribute does not exist, references elements that do not exist or references elements that are empty
  Element has no title attribute

axe description

Ensure links have discernible text

Replace placeholder text with wording that correctly reflects the real page context.

Manual review

Required: Yes

color-contrast  •  UF-00073
Review axe — manual review Color contrast WCAG 1.4.3 Contrast (Minimum) Level AA Manual review required
View issue details and remediation

Why this matters

Insufficient contrast between text and its background can make content difficult to read for users with low vision or color-vision deficiencies.

Location

DOM selector: a[href$="dsebd.org/"] > .item-icon-wrapper > .item-title | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<p class="item-title"> স্টক এক্সচেঞ্জ </p>

axe automated evidence 

Fix any of the following:
  Element's background color could not be determined due to a pseudo element

axe description

Ensure the contrast between foreground and background colors meets WCAG 2 AA minimum contrast ratio thresholds

Recommended change

Check the computed foreground and background colors of the affected text. Normal-sized text should generally have a contrast ratio of at least 4.5:1, while qualifying large text should generally have a ratio of at least 3:1.

Manual review
