#001

Link does not have a discernible accessible name

link-name  •  UF-00001
High Custom + axe Links WCAG 2.4.4 Link Purpose (In Context) / 4.1.2 Name, Role, Value Level A High - detected by both engines
View issue details and remediation

Why this matters

Screen-reader users may encounter a link without being told what it does or where it goes.

Location

DOM selector: .col-md-4:nth-child(1) > a[target="_blank"] | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<a href="https://play.google.com/store/search?q=comilla+university&amp;c=apps" target="_blank"><img src="https://www.cou.ac.bd/public/frontend/dist/app/play.png" height="35px" width="110px"></a>

axe automated evidence 

Fix all of the following:
  Element is in tab order and does not have accessible text

Fix any of the following:
  Element does not have text that is visible to screen readers
  aria-label attribute does not exist or is empty
  aria-labelledby attribute does not exist, references elements that do not exist or references elements that are empty
  Element has no title attribute

Custom scanner evidence

Link has no accessible name. Add meaningful link text, aria-label, or image alt text.

axe description

Ensure links have discernible text

Recommended change

Provide meaningful visible link text or another valid accessible name. Icon-only links should expose a concise accessible name describing their action or destination.

Suggested code pattern 

<a aria-label="Describe link destination" href="https://play.google.com/store/search?q=comilla+university&amp;c=apps" target="_blank"><img height="35px" src="https://www.cou.ac.bd/public/frontend/dist/app/play.png" width="110px"/></a>

Replace placeholder text with wording that correctly reflects the real page context.

Manual review

Required: Yes

Verify the final computed accessible name in the rendered browser accessibility tree.

View issue details and remediation

Why this matters

Location

DOM selector: .px-2.mt-4.col-md-4:nth-child(1) > .shadow.p-2.card > table > tbody > tr:nth-child(1) > td > img | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<img src="https://www.cou.ac.bd/public/upload/performance/20220922_1663843844.png" style="height: 35px; width: 40px;">

axe automated evidence 

Fix any of the following:
  Element does not have an alt attribute
  aria-label attribute does not exist or is empty
  aria-labelledby attribute does not exist, references elements that do not exist or references elements that are empty
  Element has no title attribute
  Element's default semantics were not overridden with role="none" or role="presentation"

Custom scanner evidence

Image does not have an alt attribute.

axe description

Recommended change

<img alt="[Describe the image purpose]" src="https://www.cou.ac.bd/public/upload/performance/20220922_1663843844.png" style="height: 35px; width: 40px;"/>

Ensure the contrast between foreground and background colors meets WCAG 2 AA minimum contrast ratio thresholds

Recommended change

Check the computed foreground and background colors of the affected text. Normal-sized text should generally have a contrast ratio of at least 4.5:1, while qualifying large text should generally have a ratio of at least 3:1.
