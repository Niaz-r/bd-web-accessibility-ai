#001

Button does not have a discernible accessible name

button-name  •  UF-00001
Critical axe Controls WCAG 4.1.2 Name, Role, Value Level A Axe automated finding
View issue details and remediation

Why this matters

Users of assistive technology may encounter a button without knowing its purpose.

Location

DOM selector: .hover\:text-white | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<button type="button" class="relative rounded-md hover:text-white focus:outline-none focus:ring-2 focus:ring-white" data-v-8fdcc26a="">

axe automated evidence 

Fix any of the following:
  Element does not have inner text that is visible to screen readers
  aria-label attribute does not exist or is empty
  aria-labelledby attribute does not exist, references elements that do not exist or references elements that are empty
  Element has no title attribute
  Element does not have an implicit (wrapped) <label>
  Element does not have an explicit <label>
  Element's default semantics were not overridden with role="none" or role="presentation"

axe description

Ensure buttons have discernible text

Recommended change

Provide meaningful visible button text or an appropriate accessible name such as aria-label when the control is icon-only.

Suggested code pattern 

<button aria-label="Describe button action" class="relative rounded-md hover:text-white focus:outline-none focus:ring-2 focus:ring-white" data-v-8fdcc26a="" type="button"></button>

Replace placeholder text with wording that correctly reflects the real page context.

Manual review

Required: Yes

Verify the computed accessible name after the change.

#002

Image does not have an appropriate text alternative

image-alt  •  UF-00002
Critical axe Images WCAG 1.1.1 Non-text Content Level A Axe automated finding
View issue details and remediation

Why this matters

Users who cannot perceive the image may not receive the information or function communicated by it.

Location

DOM selector: .z-\[-1\] | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<img onerror="this.setAttribute('d..." data-nuxt-img="" srcset="/_ipx/_/images/award..." class="absolute left-0 top-..." src="/_ipx/_/images/award..." style="translate: none; rot...">

axe automated evidence 

Fix any of the following:
  Element does not have an alt attribute
  aria-label attribute does not exist or is empty
  aria-labelledby attribute does not exist, references elements that do not exist or references elements that are empty
  Element has no title attribute
  Element's default semantics were not overridden with role="none" or role="presentation"

axe description

Ensure <img> elements have alternative text or a role of none or presentation

Recommended change

Determine whether the image is informative, functional, or decorative. Informative images should have concise alternative text describing their purpose. Decorative images should normally use alt="".

Suggested code pattern 

<img alt="[Describe the image purpose]" class="absolute left-0 top-..." data-nuxt-img="" onerror="this.setAttribute('d..." src="/_ipx/_/images/award..." srcset="/_ipx/_/images/award..." style="translate: none; rot..."/>

Replace placeholder text with wording that correctly reflects the real page context.

color-contrast  •  UF-00069
Review axe — manual review Color contrast WCAG 1.4.3 Contrast (Minimum) Level AA Manual review required
View issue details and remediation

Why this matters

Insufficient contrast between text and its background can make content difficult to read for users with low vision or color-vision deficiencies.

Location

DOM selector: .text-center.title-primary | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<h2 class="text-center title-primary will-change-scroll">Photo Gallery</h2>

axe automated evidence 

Fix any of the following:
  Element's background color could not be determined because it is overlapped by another element

axe description

Ensure the contrast between foreground and background colors meets WCAG 2 AA minimum contrast ratio thresholds

Recommended change

Check the computed foreground and background colors of the affected text. Normal-sized text should generally have a contrast ratio of at least 4.5:1, while qualifying large text should generally have a ratio of at least 3:1.

Manual review

Required: Yes
