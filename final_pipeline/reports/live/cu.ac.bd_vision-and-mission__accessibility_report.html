#001

Image has an empty alternative

empty_alt  •  UF-00001
Medium Custom Images WCAG 1.1.1 Non-text Content Level A Contextual/manual review Context-aware recommendation
View issue details and remediation

Why this matters

Empty alt text is appropriate for decorative images but may hide meaningful content when used on informative images.

Location

DOM selector: div.elementor.elementor-13204 > section.has_eae_slider.elementor-section > div.elementor-container.elementor-column-gap-default > div.has_eae_slider.elementor-column:nth-of-type(1) > div.elementor-widget-wrap.elementor-element-populated > div.elementor-element.elementor-element-42c2702d:nth-of-type(1) > div.elementor-widget-container > img.attachment-full.size-full | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<img alt="" class="attachment-full size-full wp-image-13203" decoding="async" fetchpriority="high" height="853" sizes="(max-width: 1280px) 100vw, 1280px" src="https://cu.ac.bd/wp-content/uploads/2025/01/cuadmin.jpg" srcset="https://cu.ac.bd/wp-content/uploads/2025/01/cuadmin.jpg 1280w, https://cu.ac.bd/wp-content/uploads/2025/01/cuadmin-300x200.jpg 300w, https://cu.ac.bd/wp-content/uploads/2025/01/cuadmin-1024x682.jpg 1024w, https://cu.ac.bd/wp-content/uploads/2025/01/cuadmin-768x512.jpg 768w" width="1280"/>

Custom scanner evidence

Image has an empty alt attribute.

Recommended change

Keep alt="" if the image is decorative. If the image communicates information or performs a function, replace the empty value with meaningful alternative text.

Context-Aware Recommendation

Visually inspect the image. If it communicates information related to “Integrity Diversity Excellence Collaboration Empathy and compassion Sustainability Dedication Inclusion”, replace alt="" with a concise description of what the image actually communicates. If it is purely decorative, keep alt="".

Why this suggestion was made: The surrounding parent text identifies the content context, but textual context alone cannot determine what the image visually contains.

Evidence: parent text Context confidence: low Language: en Decision: EMPTY_ALT_CONTEXT_AVAILABLE

Recommended action: verify decorative or informative

Visual review required

The surrounding text provides contextual evidence, but the image itself must be inspected before final alternative text is written.

Human verification: Required before implementation.

This recommendation was generated by the proposed deterministic contextual decision engine. Context confidence describes the strength of the extracted contextual evidence, not WCAG conformance certainty.

Suggested code pattern 

<img alt="[Describe image if informative]" class="attachment-full size-full wp-image-13203" decoding="async" fetchpriority="high" height="853" sizes="(max-width: 1280px) 100vw, 1280px" src="https://cu.ac.bd/wp-content/uploads/2025/01/cuadmin.jpg" srcset="https://cu.ac.bd/wp-content/uploads/2025/01/cuadmin.jpg 1280w, https://cu.ac.bd/wp-content/uploads/2025/01/cuadmin-300x200.jpg 300w, https://cu.ac.bd/wp-content/uploads/2025/01/cuadmin-1024x682.jpg 1024w, https://cu.ac.bd/wp-content/uploads/2025/01/cuadmin-768x512.jpg 768w" width="1280"/>

Replace placeholder text with wording that correctly reflects the real page context.

#003

Text color contrast requires review

color-contrast  •  UF-00003
High axe Color contrast WCAG 1.4.3 Contrast (Minimum) Level AA Axe automated finding
View issue details and remediation

Why this matters

Insufficient contrast between text and its background can make content difficult to read for users with low vision or color-vision deficiencies.

Location

DOM selector: p:nth-child(1) > strong > span | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<span style="color: #008080;">UMI:</span>

axe automated evidence 

Fix any of the following:
  Element has insufficient color contrast of 4.46 (foreground color: #008080, background color: #f6f7fd, font size: 12.0pt (16px), font weight: bold). Expected contrast ratio of 4.5:1

axe description

Ensure the contrast between foreground and background colors meets WCAG 2 AA minimum contrast ratio thresholds

Recommended change

Check the computed foreground and background colors of the affected text. Normal-sized text should generally have a contrast ratio of at least 4.5:1, while qualifying large text should generally have a ratio of at least 3:1.

Manual review

Required: Yes

axe returned this finding as incomplete when contrast could not be conclusively evaluated automatically. Background images, gradients, transparency, overlapping elements, or other rendered styling can require manual inspection.
