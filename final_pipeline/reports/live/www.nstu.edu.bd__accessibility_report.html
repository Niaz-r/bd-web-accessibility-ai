#001

Link does not have a discernible accessible name

link-name  •  UF-00001
High Custom + axe Links WCAG 2.4.4 Link Purpose (In Context) / 4.1.2 Name, Role, Value Level A High - detected by both engines
View issue details and remediation

Why this matters

Screen-reader users may encounter a link without being told what it does or where it goes.

Location

DOM selector: a[href$="academic.html"] | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<a class="nav-link" href="academic.html"></a>

axe automated evidence 

Fix all of the following:
  Element is in tab order and does not have accessible text

Fix any of the following:
  Element does not have text that is visible to screen readers
  aria-label attribute does not exist or is empty
  aria-labelledby attribute does not exist, references elements that do not exist or references elements that are empty
  Element has no title attribute

Custom scanner evidence

Link has no accessible name. Add meaningful link text, aria-label, or image alt text.

axe description

Ensure links have discernible text

Recommended change

Provide meaningful visible link text or another valid accessible name. Icon-only links should expose a concise accessible name describing their action or destination.

Suggested code pattern 

<a aria-label="Describe link destination" class="nav-link" href="academic.html"></a>

Replace placeholder text with wording that correctly reflects the real page context.

#009

Image has an empty alternative

empty_alt  •  UF-00009
Medium Custom Images WCAG 1.1.1 Non-text Content Level A Contextual/manual review Context-aware recommendation
View issue details and remediation

Why this matters

Empty alt text is appropriate for decorative images but may hide meaningful content when used on informative images.

Location

DOM selector: html > body > main > div.container.text-center:nth-of-type(9) > section.customer-logos.slider > div.slide:nth-of-type(1) > a > img | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<img alt="" height="50" src="assets/images/emergency/footer-hotline-number-img-6.jpg" width="50"/>

Custom scanner evidence

Image has an empty alt attribute.

Recommended change

Keep alt="" if the image is decorative. If the image communicates information or performs a function, replace the empty value with meaningful alternative text.

Context-Aware Recommendation

Visually inspect the image. If it communicates information related to “NSTU At a Glance”, replace alt="" with a concise description of what the image actually communicates. If it is purely decorative, keep alt="".

Why this suggestion was made: The surrounding nearby heading identifies the content context, but textual context alone cannot determine what the image visually contains.

Evidence: nearby heading Context confidence: medium Language: en Decision: EMPTY_ALT_CONTEXT_AVAILABLE

Recommended action: verify decorative or informative

Visual review required

The surrounding text provides contextual evidence, but the image itself must be inspected before final alternative text is written.

Human verification: Required before implementation.

This recommendation was generated by the proposed deterministic contextual decision engine. Context confidence describes the strength of the extracted contextual evidence, not WCAG conformance certainty.

Suggested code pattern 

<img alt="[Describe image if informative]" height="50" src="assets/images/emergency/footer-hotline-number-img-6.jpg" width="50"/>

Replace placeholder text with wording that correctly reflects the real page context.

Manual review
