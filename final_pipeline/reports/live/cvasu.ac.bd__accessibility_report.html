#001

Link does not have a discernible accessible name

link-name  •  UF-00001
High Custom + axe Links WCAG 2.4.4 Link Purpose (In Context) / 4.1.2 Name, Role, Value Level A High - detected by both engines
View issue details and remediation

Why this matters

Screen-reader users may encounter a link without being told what it does or where it goes.

Location

DOM selector: td:nth-child(1) > a[href="/"] | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<a href="/">
								<img class="top_logo" src="/static/maintheme/img/cvasu-logo-resized.jpg">
							</a>

axe automated evidence 

Fix all of the following:
  Element is in tab order and does not have accessible text

Fix any of the following:
  Element does not have text that is visible to screen readers
  aria-label attribute does not exist or is empty
  aria-labelledby attribute does not exist, references elements that do not exist or references elements that are empty
  Element has no title attribute

Custom scanner evidence

Link has no accessible name. Add meaningful link text, aria-label, or image alt text.

axe description

Ensure links have discernible text

Recommended change

Provide meaningful visible link text or another valid accessible name. Icon-only links should expose a concise accessible name describing their action or destination.

Suggested code pattern 

<a aria-label="Describe link destination" href="/">
<img class="top_logo" src="/static/maintheme/img/cvasu-logo-resized.jpg"/>
</a>

Replace placeholder text with wording that correctly reflects the real page context.

#002

Image does not have an appropriate text alternative

image-alt  •  UF-00002
Critical Custom + axe Images WCAG 1.1.1 Non-text Content Level A High - detected by both engines
View issue details and remediation

Why this matters

Users who cannot perceive the image may not receive the information or function communicated by it.

Location

DOM selector: .last_for_padding:nth-child(5) > .latest_holder.original_holder > .latest_parent > .research_image.latest_image | Ownership: page_content | Actionability: directly_reviewable

Affected HTML 

<img class="research_image latest_image" src="/media/slider_images/c2c248c8-b6a8-476d-8e8e-f34c8b38689d.jpg">

axe automated evidence 

Fix any of the following:
  Element does not have an alt attribute
  aria-label attribute does not exist or is empty
  aria-labelledby attribute does not exist, references elements that do not exist or references elements that are empty
  Element has no title attribute
  Element's default semantics were not overridden with role="none" or role="presentation"

Custom scanner evidence

Image does not have an alt attribute.

axe description

Ensure <img> elements have alternative text or a role of none or presentation

Recommended change

Determine whether the image is informative, functional, or decorative. Informative images should have concise alternative text describing their purpose. Decorative images should normally use alt="".

Suggested code pattern 

<img alt="[Describe the image purpose]" class="research_image latest_image" src="/media/slider_images/c2c248c8-b6a8-476d-8e8e-f34c8b38689d.jpg"/>

Replace placeholder text with wording that correctly reflects the real page context.
